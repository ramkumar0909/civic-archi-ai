# Security

Local-first reference project, not approved for public internet exposure. Do not ingest confidential or personal data. Report vulnerabilities privately to the repository maintainer through GitHub private vulnerability reporting when enabled; otherwise request a private contact without publishing exploit details.

Before release run dependency vulnerability scanning (OWASP Dependency-Check or equivalent), review findings, and scan tracked content for secrets. No successful security audit is claimed. See the [security architecture and residual risks](docs/architecture-definition.md#7-security-architecture-and-residual-risks) and [failure-handling design](docs/detailed-design.md#7-failure-handling-and-recovery).
